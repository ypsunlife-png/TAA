5.3投資組合優化器升級 (Markowitz → Robust Policy Engine)

現時用 Markowitz ±15% 偏離作為基礎。建議升級至 Black-Litterman + CVaR + Robust + Turnover Penalty 嘅四合一引擎：

升級項現時做法建議升級
優化器核心 Markowitz 均值方差（Mean-Variance），對均值估計敏感，易過度集中 Black-Litterman + Regime Prior — 將 HMM regime 轉成 prior return / uncertainty，減少均值估計不穩定
風險約束 只控波動率方差，無尾部風險意識 CVaR95 上限 — 唔止最小方差，加入 CVaR95 約束控制尾部風險（公式：E[L | L > VaR95] ≤ CVaR上限）
穩健性 對 expected return 直接用歷史均值，無不確定區間 Robust Optimization — 對 expected return 做不確定區間，避免過度集中（尤其 Tech / EM）
換手成本 無交易成本考慮，容易被噪音訊號驅動高頻調倉 Turnover Penalty — 目標函數加入換手成本，抑制「訊號噪音驅動」嘅高頻調倉
💡 整合提示：上述 4 項升級可循序漸進——先加 Turnover Penalty（最易，純前端可做），再上 CVaR 約束（需要歷史蒙地卡羅），最後引入 Black-Litterman Prior（需要 HMM 輸出對接）。

5.43 級事件驅動分級 (Three-Level Event Trigger)

現時得 Risk-On / Risk-Off 二元狀態。建議改做 3 級分級，每級附「恢復條件」避免來回打臉。

LEVEL 1
⚠️預警 (Watch)
市場出現異常訊號（VIX>20、Sentiment<-0.3、HMM probability 開始轉移），但未確認。
行動：只推送通知 + 凍結新加倉，等待 24h 觀察窗。
LEVEL 2
🛡️防守 (Defensive)
HMM 後驗確認進入 Risk-Off 過渡期，VIX 突破 25 持續 2 日。
行動：降低高 beta 資產 5%-10%，資金轉 Gold / IG Bond。
LEVEL 3
🚨保本 (Capital Preservation)
連續 3 日 Risk-Off、Sentiment < -0.6、出現 regime-break 信號。
行動：啟動硬風控——EM 減 15%，現金 / 短債增加 20%。
